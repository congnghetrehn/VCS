# Virtual Commissioning Studio (VCS)

Nền tảng web mô phỏng điều khiển công nghiệp trước commissioning: soft-PLC Siemens, plant model, test tự động từ I/O list + C&E, báo cáo FAT, OPC UA/Modbus/S7, HMI, kết nối PLCSIM Advanced. Local-first, on-prem.

## Cách chạy

> Đang ở milestone M0 (chưa bắt đầu). Cách chạy đầy đủ sẽ được cập nhật ở P0.7.

```sh
pnpm install --frozen-lockfile
pnpm dev
```
