## Tiêu chí CẦN KIỂM TAY (chủ sản phẩm làm)

Các mục dưới đây không phải lỗi code — chúng là kiểm chứng bằng tay/dữ liệu thật mà chỉ chủ sản phẩm làm được. AI đã chạy được phần tự động; phần này chờ anh:

1. **Gửi file I/O thật** (X-003 A, ≥ 100 tín hiệu, đã ẩn danh theo D-003 A) → AI đo §14 #4 (≥ 90% tín hiệu, ≥ 95% thiết bị) và đóng OQ-380.
2. **VERIFY M2 §14 với PLCSIM + mã thật** (M2 §16 mục 2): dải raw analog (0..27648, over/under-range), giá trị wire-break AI, channel base 0 hay 1, ký hiệu địa chỉ trong I/O list (E/A hay I/Q).
3. **Số liệu motor thật** (M2 §16 mục 3): contactor pull-in/feedback `startDelayMs`/`stopDelayMs`, VFD ramp, valve travel.
4. **Rà fault list từng model (§7)** và bổ sung lỗi hay gặp ngoài hiện trường mà spec chưa có (M2 §16 mục 4).
5. **Chạy tay scenario A–D (§11.4) trên PLCSIM + logic thật** nếu có, so hành vi PLC vs feedback (M2 §16 mục 5).
6. **Rà `docs/semantics.md` §15–§16 bằng kiến thức PLC** (kế thừa từ M1 — chưa làm).
7. **Đo lại perf-scroll 20 000 dòng trên máy thật** — VM đo 30,7/24,3 FPS so với ngưỡng 50 (ngưỡng KHÔNG hạ); cần số trên phần cứng thật.
8. **Chạy gate trên máy Windows thật** — phần còn thiếu của T-001: e2e + trạng thái .NET SDK/Playwright (`docs/verify-owner-guide.md/§4`).
9. **Probe FB_Probe** (D-010 A, OQ-400) — đo layout TIA rồi gửi offsets (`docs/verify-owner-guide.md`, mục cuối).
10. **Tick R-010** (mục review P2.8, OWNER-INBOX) — đã implement + gate xanh, chờ anh duyệt.
11. **Ký M2** (tier C) sau khi duyệt xong các mục trên.
